# Research bookmarks and company snapshots

The 58 company files are retained unchanged as supplied design observations. This revision inventories them; it does not claim a new full reading or current website audit of all 58. Read the selected file and check current official guidance before treating its token, behavior or brand claim as current. Strong praise in an older snapshot is the author’s interpretation, not a verified usability result.

## Select by the question

Color: Stripe, Claude, Linear, Revolut, Spotify. Typography: Apple, Vercel, Tesla, Notion, Ferrari. Layout: Linear, Figma, Superhuman, Raycast. Dark surfaces: Linear, Cursor, Warp, Sentry, SpaceX. Warm tone: Claude, Notion, Airbnb, Wise. Luxury: Ferrari, Lamborghini, Tesla, BMW, Superhuman. Developer workflows: Vercel, Supabase, Raycast, Cursor, Warp. These are starting associations, not rankings.

## Learning sources

The original source families below remain a reading list. They were not all opened in this revision. Select sources for the actual question; verify current URLs, editions, platform behavior and licensing when needed.

### Design Philosophy & Thinking

| Source | Use it for |
|---|---|
| Frank Chimero, *The Shape of Design* (shapeofdesignbook.com) | Design process and judgment in context. |
| Frank Chimero, "What Screens Want" | How screen behavior differs from print. |
| Frank Chimero, "The Web's Grain" | Designing with the web’s capabilities. |
| Julie Zhuo, *The Looking Glass* (lg.substack.com) | Developing and critiquing visual judgment. |
| Steve Schoger & Adam Wathan, *Refactoring UI* | Concrete interface layout, color and typography tactics. |
| Erik Kennedy, "7 Rules for Creating Gorgeous UI" (learnui.design) | Demonstrated UI composition techniques. |
| Gary Hustwit, *Rams* documentary | A documentary perspective on Rams’ practice. |
| Jony Ive, Ian Parker profile (The New Yorker, 2015) | A reported profile of material exploration and design process. |

### Color & Visual Perception

| Source | Use it for |
|---|---|
| Josef Albers, *Interaction of Color* (app edition) | Visual experiments in color relationships. |
| Lea Verou, oklch.com | An interactive OKLCH palette exploration tool; verify current authorship/tool details. |
| Stripe, "Designing accessible color systems" (stripe.com/blog) | A company account of color-system engineering. |
| Cynthia Brewer, ColorBrewer (colorbrewer2.org) | Data-visualization palette selection with palette-specific suitability checks. |
| Radix Colors documentation (radix-ui.com/colors) | Twelve-step semantic scales with explicitly scoped pairings. |
| Adam Argyle (Chrome DevRel) | Practical CSS color implementation material. |

### Typography

| Source | Use it for |
|---|---|
| Matthew Butterick, *Practical Typography* (practicaltypography.com) | Practical typography guidance for readable text. |
| Robert Bringhurst, *Elements of Typographic Style* | Typography, measure, rhythm and type selection. |
| Oliver Reichenstein, "Web Design is 95% Typography" (ia.net) | An argument for giving text design substantial attention; the title is not an effort-allocation formula. |
| Tim Brown, "More Meaningful Typography" (alistapart.com) | Modular type-scale methods. |
| Rasmus Andersson, Inter design notes (rsms.me/inter) | Typeface design and small-size rendering considerations. |
| Typewolf (typewolf.com) | Examples of type in use; inspect actual live behavior when relevant. |
